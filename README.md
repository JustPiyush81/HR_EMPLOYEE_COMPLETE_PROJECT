# HR_EMPLOYEE_COMPLETE_PROJECT
## HR Employee Analytics Dashboard  An end-to-end HR data analytics project built in Microsoft Excel.
**What's included:**
- Raw uncleaned HR employee dataset (50 records)
- Data cleaning using Power Query (handled mixed case, duplicates, blank values, inconsistent formats)
- 4 Pivot Reports — Department-wise Salary & Bonus, Employment Type Distribution, State-wise Performance Rating, Gender-wise Attendance & Project Count
- Interactive Dashboard with KPI Cards, Charts, and Slicers
- Key Insights Sheet with actionable HR recommendations

**Tools Used:** Microsoft Excel, Power Query, Pivot Tables, Slicers

**Dataset:** HR domain — 50 employees across IT, Finance, HR, Marketing & Operations departments
